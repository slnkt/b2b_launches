# Партнерские запуски Bioniq

Внутренний сайт с логикой каждого партнерского запуска. Статика: HTML, CSS, vanilla JS, без сборки и бэкенда. Работает на любом статическом хостинге, в том числе из подпапки: все пути относительные.

## Структура

```
index.html                   разводящая страница
encore-metaboscan/index.html страница запуска
assets/                      стили, скрипт, логотипы, памятки PDF
data.js                      весь контент
robots.txt                   закрыт от индексации
```

## Как править контент

Весь текст лежит в `data.js`. Верстку править не нужно.

- Незаполненное значение пишется как `"[ЗАПОЛНИТЬ: что именно]"` или `null`. На странице оно выводится красной плашкой. Плашку можно ставить внутри фразы.
- Пустая строка `""` в гарантиях означает «не применимо», выводится как тире.
- Даты в формате `ГГГГ-ММ-ДД`, на странице показываются как `ДД.ММ.ГГГГ`.
- Статус запуска: `preparing`, `live`, `finished`. Статус вопроса: `open`, `resolved`.

## Как добавить партнерство

1. Добавить объект в массив `launches` в `data.js` с уникальным `slug`.
2. Скопировать папку `encore-metaboscan` под именем этого `slug`. В `index.html` новой папки поменять `data-launch="..."` на новый slug (или удалить атрибут: slug берется из имени папки).

## Памятки PDF

Положить файлы в `assets/` и указать путь в `data.js`: `memo: "../assets/metaboscan-blood.pdf"`. Пока `memo: null`, вместо кнопки «Скачать памятку» показывается плашка.

## Локальный просмотр

Открыть `index.html` в браузере или запустить любой статический сервер, например:

```
python3 -m http.server 8080
```
